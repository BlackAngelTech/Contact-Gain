Need to know

Frequently asked questions

Can the same number be registered twice?

No. The server normalizes common phone-number formats and rejects a number if that normalized number is already stored.

Can an admin turn registration off?

Yes. The admin control center has a registration switch and a separate maintenance mode.

Can contacts be exported?

Yes. Authorized admins can export VCF or CSV, or create a JSON backup. Export access can be disabled from the admin panel.

Can I change the public text?

Yes. The admin panel includes site-title and welcome-message controls.
